# Port Status Checker

## Description
A Python project that checks whether a TCP port is
reachable on a specified hostname or IP address.

## Features
- Accepts a hostname or IP address.
- Accepts a port number from 1 to 65535.
- Reports whether the port is open or closed/filtered.
- Handles invalid port numbers and network errors.
- Uses Python's built-in socket module.

## Requirements
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run: python port_checker.py
4. Enter the target hostname/IP and port number.

## Technology
Python, Socket Programming, Computer Networks
